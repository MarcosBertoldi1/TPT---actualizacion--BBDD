Hardware, Software y Sistema Operativo

Video explicativo introductorio.

← Volver a recursos

Descripción

En este video vamos a conocer entre los conceptos de Arquitectura y Organización de las computadora.

Hardware: conjunto de componentes físicos de la computadora (lo que se puede tocar).

Software: conjunto de programas e instrucciones que permiten realizar tareas.

Sistema operativo: software principal que administra el hardware y permite ejecutar aplicaciones.

El hardware proporciona los recursos físicos, el sistema operativo los administra y actúa como intermediario, y el software utiliza esos recursos para que el usuario pueda realizar distintas tareas.
